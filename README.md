# 測点ノート｜測量士補・無料240問問題集

- **公開URL:** https://nyantaro3588.github.io/sokuryo-quiz/
- **入門20問（旧バージョンを保存）:** https://nyantaro3588.github.io/sokuryo-quiz/intro20.html
- **総合サイト:** https://nyantaro3588.github.io/sokuryo/

## 提供機能

オリジナル予想問題 **8分野×30問＝240問**。分野別・全分野ランダム・10/20/30/全問演習・端末内の誤答履歴・4択と解説に対応します。

64問に手入力型の計算サポートを割り当て、原稿中の画像挿入位置に対応する49問に模式SVG図を表示します。計算機は自動で問題文の数値を入力しません。スマートフォンのみでも演習を続けられる構成です。

## ファイル構成

- `index.html` — 240問の公開用HTML。問題データと描画・計算ロジックを同梱し、追加ダウンロードなしでも表示可能。
- `data/questions.json` — 編集・検査用の240問データ。記事本文から整形したソース。
- `intro20.html` — 移行前の20問版を残したもの。
- `docs/question-review-log.md` — 復元した解答および修正履歴。
- `sitemap.xml` — 公開ページ一覧。

## 品質と注意点

元原稿は7問の解答・解説が欠落していたため、各問の選択肢から暫定復元しました。そのほか明白な解説・選択肢の不一致を編集しています。**専門法令を含め全240問の公式資料照合・最終監修は未完了**です。原稿どおりの240問をベースとした学習β版として運用し、校正を継続してください。

画像は元のnote記事から直接移しておらず、縮尺どおりとは限らない独立SVG模式図です。

## インストール型PWA（2026-10-13）

- `manifest.webmanifest` — アプリ名、開始URL、インストール用アイコン、standalone表示。
- `sw.js` — 240問本体・入門20問・アイコン等を同一オリジンに事前キャッシュし、オフライン表示を支援。
- `icons/icon-192.png` と `icons/icon-512.png` — PWAアイコン。
- `index.html` — 対応ブラウザで「アプリをインストール」を提示し、更新時には利用者が許可してからアプリを再読み込み。
- AndroidのChrome（Google Play開発環境がある端末）ではWebAPKとしてインストールされることがあります。ネイティブAPKやストア公開とは異なります。
- iOSでは共有メニューから「ホーム画面に追加」を使うのがOSのPWAインストール手順です。
- Service worker初回登録は通信が必要。インストール後のオフライン動作・ブラウザ毎のインストール表示は実機テストを要します。アプリの履歴は引き続き端末内保存です。
