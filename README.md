## 提供機能

オリジナル予想問題 **8分野×60問＝480問**。分野別・全分野ランダム・5/10/20/30/60/120/240/480問などの演習・端末内の誤答履歴・4択と解説に対応します。

旧64問＋新84問、計148問に手入力型の計算サポートを割り当て、原稿中の画像挿入位置に対応する49問に模式SVG図を表示します。計算機は自動で問題文の数値を入力しません。スマートフォンのみでも演習を続けられる構成です。

## ファイル構成

- `index.html` — 480問の公開用HTML。問題データと描画・計算ロジックを同梱し、追加ダウンロードなしでも表示可能。
- `data/questions.json` — 編集・検査用の480問データ。旧240問と新規240問を合わせた編集用ソース。
- `intro20.html` — 移行前の20問版を残したもの。
- `docs/question-review-log.md` — 復元した解答および修正履歴。
- `sitemap.xml` — 公開ページ一覧。

## インストール型PWA（2026-10-13）

- `manifest.webmanifest` — アプリ名、開始URL、インストール用アイコン、standalone表示。
- `sw.js` — 480問本体・入門20問・アイコン等を同一オリジンに事前キャッシュし、オフライン表示を支援。

- AndroidのChrome（Google Play開発環境がある端末）ではWebAPKとしてインストールされることがあります。ネイティブAPKやストア公開とは異なります。
- iOSでは共有メニューから「ホーム画面に追加」を使うのがOSのPWAインストール手順です。
- Service worker初回登録は通信が必要。インストール後のオフライン動作・ブラウザ毎のインストール表示は実機テストを要します。アプリの履歴は引き続き端末内保存です。
